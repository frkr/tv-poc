## 2025-02-15 - [CRITICAL] Prevent Hardcoded Secrets in Wrangler Configs
**Vulnerability:** Found hardcoded `GOOGLE_CLIENT_SECRET` and `SESSION_SECRET` values inside `site/wrangler.jsonc` and subsequently reflected into `site/worker-configuration.d.ts` via type generation.
**Learning:** Cloudflare Workers use `wrangler.json`/`wrangler.jsonc` to define environment bindings, but it's not secure for storing production secrets. Since `wrangler types` generates TS interfaces using values from `wrangler.jsonc` by default, hardcoding the strings leads to literal string typing for those secrets, leaking them directly into source code that often gets committed.
**Prevention:** Always use `.dev.vars` for local secrets and `wrangler secret put` for production secrets. For type generation with `pnpm run cf-typegen`, ensure the actual string values are missing from `wrangler.jsonc` so they are correctly typed as `string` without exposing a literal constant. Add `.dev.vars` to `.gitignore`.
