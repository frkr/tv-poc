## 2025-03-05 - [Cloudflare Workers Secrets Leakage via wrangler.jsonc]
**Vulnerability:** Hardcoding sensitive variables (like `GOOGLE_CLIENT_SECRET` and `SESSION_SECRET`) inside `wrangler.jsonc`'s `vars` section causes them to be leaked as literal strings into the generated `worker-configuration.d.ts` type definition file when running `wrangler types` (or `pnpm run cf-typegen`). Since `worker-configuration.d.ts` is committed to version control, the secrets become exposed in the repository.
**Learning:** In a Cloudflare Workers project utilizing `wrangler types`, the `vars` object in `wrangler.jsonc` is strictly for public/non-sensitive environment variables. When secrets are placed there for local development convenience, they inadvertently leak into Git via the generated TypeScript interfaces.
**Prevention:** Always use `.dev.vars` for local secrets and ensure `.dev.vars` is included in `.gitignore`. For production, configure secrets securely via the Cloudflare dashboard or Wrangler CLI (`wrangler secret put`). Use empty strings for secret variables in `wrangler.jsonc` so they are still strongly typed but their actual values remain hidden from the generated type definitions.
